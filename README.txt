SAWIRKAYD PWA — WINDOWS + IPHONE

App-kan wuxuu:
- Sawirro ka soo geliyaa iPhone ama laptop
- Sawirrada ku kaydiyaa browser-ka qalabkaas (IndexedDB)
- Ku tusaa gallery
- Sawir weyn u furaa
- Sawir tirtiraa
- Markii website HTTPS lagu host-gareeyo, iPhone Home Screen ayaa lagu dari karaa

MUHIIM:
Sawirradu hadda qalab kasta si gaar ah ayay ugu kaydsan yihiin.
Sawirrada laptop-ka lagu daro si otomaatig ah iPhone uguma gudbaan.
Si labada qalab sawirro isku mid ah u arkaan waxaa loo baahan yahay cloud/database,
taas version dambe ayaa lagu dari karaa.

WINDOWS — SI AAD U TIJAABISO:
1. ZIP-ka fur.
2. Folder-ka SawirKayd_PWA fur.
3. index.html laba jeer guji.
4. Browser-ka ayuu app-ku ka furmayaa.
5. Taabo + Ku dar oo sawir dooro.

IPHONE — SI APP AHAAN LOOGU DARO:
Waxaad marka hore folder-kan ku host-gareynaysaa website HTTPS sida GitHub Pages.
Kadib:
1. Website-ka ku fur Safari iPhone.
2. Taabo Share.
3. Dooro Add to Home Screen.
4. Dooro Add.
5. SawirKayd wuxuu kasoo muuqanayaa Home Screen sida app.

Haddii aad rabto, tallaabada xigta waxaan kuu diyaarin karnaa GitHub Pages step-by-step.
